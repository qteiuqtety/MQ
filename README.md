## 煤球截图识别（快速开始）

1. 下载 [MeiQiu-Screenshot-OCR-Installer.zip](https://github.com/qteiuqtety/MQ/releases/download/meiqiu-ocr-v1.0.0/MeiQiu-Screenshot-OCR-Installer.zip)
2. 解压后双击 `安装并生成工具.bat`
3. 输入智谱 Z.AI API Key（申请：https://open.bigmodel.cn/ ）
4. 运行生成的 `煤球截图识别.exe`，设置快捷键后即可使用

> 仅修复 API 配置时可运行包内 `修复API配置.bat`。
