# MQ · 煤球小工具

存放带煤球图标的便携小工具，下载后解压即可用。

## 工具列表

| 工具 | 说明 | 下载 |
|------|------|------|
| **DWMfix 中文便携版** | 缓解 Windows 多显示器 / 游戏时副屏卡顿 | [Releases](https://github.com/qteiuqtety/MQ/releases) |

## 使用说明

1. 打开 [Releases](https://github.com/qteiuqtety/MQ/releases)
2. 下载对应 zip
3. 解压后运行其中的 `.exe`（请整夹复制，保持 `_internal` 等依赖文件夹在一起）

后续煤球系列工具都会放在本仓库 Releases 中。
